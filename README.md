# Tzemed Barzel — Landing Page (Budget Table)

דף נחיתה לטבלת התקציב של צמד ברזל. כולל:

- `index.html` — דף נחיתה ראשי עם טופס לידים (שם / טלפון / מייל) וטיימר ספירה לאחור.
- `thank-you.html` — דף תודה עם כפתור הצטרפות לקבוצת הוואטסאפ.
- `assets/logo-gold.png` — לוגו צמד ברזל (וריאנט זהב, רקע שקוף).

## פיתוח לוקאלי

```bash
cd landing-page-train-budget
python3 -m http.server 8910
```
פתח את http://localhost:8910/index.html

## פריסה
מומלץ לפרוס דרך Vercel / Netlify (גרירה של התיקייה לדשבורד, או חיבור ישיר לריפו).
